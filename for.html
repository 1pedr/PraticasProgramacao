O que é o for?

Outra estrutura de repetição. No while, o início, a condição e o passo ficam espalhados. No for, os três ficam juntos numa linha, separados por ;. 

for (início; condição; passo) {
  instrução;
}
  • início: roda uma vez só, antes de tudo (let i = 1).
  • condição: testada antes de cada rodada, como no while (i <= 10).
  • passo: roda no fim de cada rodada (i++).

Por costume, a contadora do for se chama i (de índice).

for x while: o mesmo laço

Os dois códigos abaixo fazem exatamente a mesma coisa.

// while
let i = 1;              // início
while (i <= 10) {       // condição
  console.log(i);
  i++;                  // passo
}

// for
for (let i = 1; i <= 10; i++) {
  console.log(i);
}

Use o for quando você já sabe quantas vezes vai repetir (de 1 a 10, as 4 notas...). Use o while quando depende de algo que muda no caminho (repetir até o usuário digitar certo).

Exemplo 1: contar e somar

O mesmo exemplo da página de repetição, agora com for. A soma continua sendo a acumuladora; o i é a contadora. 

let soma = 0;

for (let i = 1; i <= 10; i++) {
  console.log(i);
  soma += i;
}

console.log("O somatório é: " + soma); // 55

Exemplo 3: contagem regressiva

        

          O for também anda para trás: começa alto, a condição
          vira >= e o passo vira i--.
        

        
for (let i = 10; i >= 1; i--) {
  console.log(i);
}
console.log("Fogo!");

        

          Cuidado: com i++ aqui, o i só aumenta, a
          condição i >= 1 nunca fica falsa e vira
          loop infinito.
