1. O que é

Bootstrap é um framework de CSS: um arquivo cheio de estilos prontos que você aplica escrevendo o nome de uma classe no HTML. Em vez de escrever o CSS de um botão (cor, borda, espaço, cantos), você escreve class="btn btn-dark" e ele já aparece estilizado.

Sem BootstrapCom Bootstrap
você escreve o CSS de cada elementovocê escolhe classes que já existem
cada página fica com um jeitofontes, cores e tamanhos padronizados
celular exige CSS à partelayout responsivo já incluso

Foi criado no Twitter (por Mark Otto e Jacob Thornton) e hoje é um dos projetos de código aberto mais usados do mundo.

2. Como ligar na página

Dois passos: um <link> para o CSS no <head> e um <script> para o JS no fim do <body>. Os endereços vêm de um CDN (Content Delivery Network): uma rede de servidores que guarda cópias do arquivo e entrega pelo mais próximo de quem abre a página. Não precisa baixar nada. 

<head>
  <!-- CSS do Bootstrap -->
  <link rel="stylesheet"
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" />

  <!-- O nosso CSS vem DEPOIS, para poder sobrescrever o Bootstrap -->
  <link rel="stylesheet" href="carrinho.css" />
</head>
<body>
  ...
  <!-- JS do Bootstrap: só para botões, janelas e alertas -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
ArquivoPara quêTag
bootstrap.min.cssas classes de estilo (obrigatório)<link>
bootstrap.bundle.min.jscomponentes que precisam de JS (menu que abre, janela modal, alerta)<script>

Onde pegar os links:

  • Site oficial: getbootstrap.com, seção Download/Quick start, que traz o trecho pronto para copiar.
  • Template de página: sites de modelos (como o bbbootstrap) têm uma aba Resources com os links do CDN que o modelo usa. Dá para copiar de lá e colar no seu <head>.
  • Versão: o número no endereço (@5.3.3) é a versão. Modelos mais antigos usam a 4 (e o jQuery junto); a 5 não precisa de jQuery. Misturar versões quebra o visual: use CSS e JS da mesma.

3. O que tem dentro do link

O endereço do CSS é um arquivo comum: cole no navegador e ele mostra o conteúdo. É lá que estão todas as classes.

  • bootstrap.css (sem .min): o código legível, com mais de 10 mil linhas de regras como .btn { ... } e .p-3 { padding: 1rem }.
  • bootstrap.min.css: o mesmo conteúdo sem espaços nem quebras de linha (minificado), para carregar mais rápido. É o que se liga nas páginas.

Dica: para descobrir o que uma classe faz, abra o bootstrap.css e procure (Ctrl+F) pelo nome. Ou use a documentação, que tem exemplo de cada uma. 

https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.css       (legível)
https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css   (o que se liga)

4. Como usar

Depois de ligado, é só escrever as classes no atributo class, separadas por espaço. Cada uma faz uma coisa; juntas, se somam. 

<!-- Botão: btn = formato de botão; btn-dark = cor; btn-sm = tamanho pequeno -->
<button class="btn btn-dark btn-sm">Continuar</button>

<!-- Tabela: table = estilo; align-middle = centraliza na vertical -->
<table class="table align-middle"> ... </table>

<!-- Caixa central com largura máxima: container -->
<main class="container"> ... </main>

Grade (row e col): a página é dividida em 12 colunas. Você diz quantas cada bloco ocupa, e ele se ajusta ao tamanho da tela. 

<div class="container">
  <div class="row">                    <!-- uma linha de colunas -->
    <div class="col-md-8">...</div>   <!-- 8 de 12 no computador; empilha no celular -->
    <div class="col-md-4">...</div>   <!-- 4 de 12 -->
  </div>
</div>

md é o tamanho de tela a partir do qual as colunas ficam lado a lado (sm, md, lg, xl). Abaixo dele, empilham.

7. Quando usar (visão de mercado)

  • Vantagens: rápido, padronizado, responsivo e com documentação e exemplos para quase tudo. Bom para protótipos, painéis internos e páginas simples.
  • Desvantagens: muitas classes e <div> deixam o HTML grande; sites com visual muito próprio acabam brigando com o estilo padrão. Por isso o CSS próprio vem depois dele.
  • Alternativas: Tailwind CSS (classes ainda mais granulares) e bibliotecas de componentes ligadas a React, Vue ou Angular. Cada uma tem vantagens e desvantagens; é questão de projeto e de gosto.
  • Documentação oficial: getbootstrap.com/docs/5.3.
