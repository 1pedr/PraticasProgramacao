HTML: estrutura da página

TermoO que éExemplo
<!doctype html>Avisa que é HTML moderno. Primeira linha.<!doctype html>
<html>Caixa que guarda a página inteira.<html lang="pt-BR">
<head>Informações da página (não aparecem no corpo).título, CSS, meta
<meta>Configuração: acentos (charset) e celular (viewport).<meta charset="UTF-8" />
<title>Nome que aparece na aba do navegador.<title>For</title>
<link>Liga um arquivo externo, como o CSS.<link rel="stylesheet" href="css/estilo.css" />
<body>Tudo que aparece na tela. 
<script>Liga ou escreve JavaScript. Fica no fim do body.<script src="js/for.js"></script>
<!-- -->Comentário: o navegador ignora.<!-- Rodapé -->

TermoO que éExemplo

constCria variável que não muda.const qtd = 4;
varJeito antigo de criar variável. Prefira let/const. 
texto (string)Entre aspas ou crases."Gol"
númeroSem aspas. Decimal usa ponto.8.5

JS: operadores

TermoO que éExemplo
+ - * /Soma, subtração, multiplicação, divisão. Com texto, + junta."7" + "8" → "78"
%Resto da divisão.10 % 3 → 1
**Potência.2 ** 3 → 8
+=Soma e guarda.soma += i = soma = soma + i
++ --Soma 1 / tira 1.i++
=Guarda um valor (atribuição). Não compara!let i = 1
=== !==Igual / diferente (valor e tipo).nota === 10
< > <= >=Menor, maior, menor ou igual, maior ou igual.i <= 10
&&E: as duas condições precisam ser verdadeiras.nota >= 0 && nota <= 10
||OU: basta uma ser verdadeira.nota < 0 || nota > 10
!NÃO: inverte true/false.!true → false

JS: decisão e repetição

TermoO que éExemplo
if / elseSe a condição for verdadeira faz um bloco; senão, o outro.if (media >= 7) { } else { }
? :Ternário: if/else em uma linha.media >= 7 ? "Aprovado" : "Reprovado"
switchCompara um valor com vários case.switch (mes) { case 1: ... }
breakSai do switch (ou do laço). 
defaultO "senão" do switch: nenhum case bateu. 
whileRepete enquanto a condição for verdadeira. Testa ANTES.while (i <= 10) { }
do...whileRoda pelo menos 1 vez. Testa DEPOIS.do { } while (nota > 10);
forInício, condição e passo numa linha.for (let i = 1; i <= 10; i++)
for...inPassa pelos NOMES das propriedades de um objeto.for (let atributo in pessoa)
for...ofPassa pelos VALORES de um array ou texto.for (let carro of carros)
continuePula para a próxima rodada do laço. 

JS: funções, objetos e arrays

TermoO que éExemplo
functionBloco de código com nome, que roda quando é chamado.function montarTabuada(numero) { }
parâmetroValor que a função recebe, entre ( ).numero em montarTabuada(numero)
returnDevolve um resultado e encerra a função.return soma;
argumentoValor passado ao chamar a função.2 e 5 em somar(2, 5)
hoistingFunção de declaração pode ser chamada antes de aparecer no código.somar(1, 2) antes do function somar
escopoOnde algo existe. Função criada dentro de outra só existe lá dentro.quadrado dentro de addQuadrado
function ( ) { }Função de expressão: guardada numa variável.const somar = function (x, y) { ... }
=>Arrow function: jeito curto de escrever função.const somar = (x, y) => x + y
newChama uma função construtora e cria um objeto novo.new Pessoa("Ana", "Silva")
thisDentro da construtora, é o objeto que está sendo criado.this.nome = nome
function*Função geradora: pausa em cada yield.function* contar() { yield 1; }
yieldPausa a geradora e entrega um valor.yield 1
.next()Continua a geradora. Devolve { value, done }.{ value: 1, done: false }
recursãoFunção que chama a si mesma com um problema menor.return x * fatorial(x - 1)
caso baseCondição que faz a recursão parar.if (x <= 1) return 1
stack overflowErro de chamadas demais (recursão sem caso base).Maximum call stack size exceeded
FibonacciSequência em que cada número é a soma dos dois anteriores.0, 1, 1, 2, 3, 5, 8...
parseInt()Texto → número inteiro (corta os decimais).parseInt("2.9") → 2
.innerHTMLEscreve dentro de um elemento (aceita tags HTML).res.innerHTML = "Oi"
onloadEvento "a página terminou de carregar".<body onload="iniciar()">
objeto { }Vários valores com nome, juntos.{ nome: "Orion", nota: 8 }
. e [ ]Pegam um valor do objeto.pessoa.nome = pessoa["nome"]
array [ ]Lista de valores. Posição (índice) começa em 0.carros[0] → "Gol"
.lengthTamanho de um array ou texto.carros.length → 4
new Array()Outro jeito de criar array. Prefira [ ].new Array(10) → 10 posições vazias
.push()Adiciona no fim. Devolve o novo tamanho.carros.push("Fiesta")
.unshift()Adiciona no começo.carros.unshift("Palio")
.pop()Remove o último. Devolve o removido.carros.pop()
.shift()Remove o primeiro. Devolve o removido.carros.shift()
.splice()Insere, troca ou exclui numa posição: (posição, quantos remover, item).carros.splice(1, 1, "Uno")
.sort()Ordena (compara como texto!).idades.sort()
console.table()Mostra um array como tabela no Console (F12).console.table(carros)
array de arraysArray cujos itens são arrays (matriz).[["João", 24], ["Maria", 30]]
[i][j]Acessa linha i, coluna j de uma matriz.funcionarios[0][2] → 1800
array de objetosLista em que cada item é um objeto { }.pessoas[2].nome → "José"
for aninhadoUm for dentro de outro: o de dentro roda inteiro a cada volta do de fora.linhas (i) e colunas (j)

JS: números e textos

TermoO que éExemplo
Number()Transforma texto em número.Number("8") → 8
NaN"Não é um número": conversão que falhou.Number("abc")
Number.isInteger()É número inteiro?Number.isInteger(7.5) → false
Number.isFinite()É um número válido (não NaN)? 
.toFixed(2)Mostra com 2 casas decimais.(7.5).toFixed(2) → "7.50"
Math.floor()Arredonda para baixo.Math.floor(7.9) → 7
String()Transforma em texto.String(10) → "10"
.trim()Tira espaços do começo e do fim." oi ".trim() → "oi"
.replace()Troca um pedaço do texto."8,5".replace(",", ".")
.padEnd()Completa com espaços até um tamanho.alinhar o teste de mesa
.includes()O texto contém este pedaço?"Gran".includes("ra") → true
.repeat()Repete um texto N vezes."ab".repeat(3) → "ababab"
.join()Junta os itens de um array num texto.["a", "b"].join("-") → "a-b"
.toLowerCase()Deixa tudo minúsculo."UL".toLowerCase() → "ul"
