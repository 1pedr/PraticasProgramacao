Verificador de Notas

Quais foram suas notas?

Código desta seção: js/verificador.js, seção 2.

Digite três notas de 0 a 10. A classificação usa a média delas.










Processo do cálculo

Código desta seção: js/verificador.js, seção 1.

  1. Ler as três notas digitadas.
  2. Somar as notas e dividir a soma por 3.
  3. Comparar a média com os limites para classificar.
const media = (nota1 + nota2 + nota3) / 3;

if (media >= 7) {
  classificacao = "Aprovado";
} else if (media >= 5) {
  classificacao = "Recuperação";
} else {
  classificacao = "Reprovado";
}

A média igual ou maior que 7 aprova. Se for menor que 7, mas igual ou maior que 5, fica em recuperação. Abaixo de 5, reprova.
