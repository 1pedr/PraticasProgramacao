Variáveis

O que é uma variável?

Uma variável é uma "caixinha com etiqueta": o nome é a etiqueta e o valor é o que está guardado dentro.

O resultado de cada exemplo abaixo é escrito pelo arquivo js/variaveis.js. Abra ele no VS Code e compare com a tela.

Código desta seção: js/variaveis.js, seção 1.

  • let: o valor pode mudar depois.
  • const: o valor não muda (constante).
  • var: jeito antigo, evite.
