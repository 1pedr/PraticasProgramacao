O que é entrada e saída?

Saída: o programa mostra algo para o usuário.
Entrada: o usuário envia algo para o programa.

O código está em js/entrada-saida.js. Teste os botões e depois veja como cada um foi feito.

Mostra uma mensagem no console. Aperte F12 e abra a aba Console para ver.
