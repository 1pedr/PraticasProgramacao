O que é

O Claude Code é o Claude que lê e edita os arquivos do seu projeto. O mesmo Claude pode ser aberto de dois jeitos:

Painel do VS CodeTerminal
Como abreícone do Claude na barra lateraldigitar claude no terminal
Aparênciabotões, visualsó texto
Colar printsimplesdepende do terminal
Contador de contexto fixonão garantidosim (status line)
! comando rápidonãosim

Enquanto aprende, o painel é o mais fácil. Os dois convivem: não precisa escolher um só.

Pedidos prontos (como usamos no caderno)

Não precisa de comando: é só escrever. Estas frases já funcionam:

EscrevaO que acontece
"próxima aula" + PDF ou printvira uma página nova do caderno, no mesmo estilo
"o que é isso?" + print da aulaexplica o código da professora
"revisa @js/for.js sem alterar nada"só lê e aponta problemas
"upe no github"testa, faz o commit e envia
"restaure, acho que fiz besteira"confere o que mudou e conserta
"abre o glossario.html"abre a página no navegador
"salve" / "lembre que..."guarda na memória para os próximos chats

Dica: um chat novo por aula. O Claude lembra seu estilo e o progresso pela memória, e conversas muito longas perdem detalhes.

Comandos com /: como funcionam

  • Digite / no começo da mensagem: aparece a lista. Continue digitando para filtrar.
  • O que vem depois do nome é o argumento: /compact foque na aula de for.
  • Nas tabelas, <algo> é obrigatório e [algo] é opcional.
  • Apelidos fazem a mesma coisa: /new = /clear.
  • Nem todo comando aparece para todo mundo: depende do plano, do sistema e de onde você está (painel ou terminal). Se não aparece na lista, não está disponível para você.
  • Comando enviado enquanto o Claude responde entra na fila e roda depois.

Fonte: documentação oficial (code.claude.com/docs/en/commands), versão 2.1.287.

Comandos que saíram

Se achar em tutorial antigo: /vim (agora em /config), /pr-comments (peça direto ao Claude) e /ultraplan (use /plan) foram removidos.

Você também pode criar seus próprios comandos (skills): peça "cria um comando /aula que faz...".

Desfazer um erro

  1. Ctrl+Z no arquivo aberto desfaz as últimas edições.
  2. Pedir ao Claude: "restaure", "volta como estava".
  3. GitHub: cada envio é um ponto seguro. Envie quando algo estiver funcionando.

Se ficar perdido

  1. Esc para parar o que está acontecendo.
  2. /help para ver os comandos.
  3. Pergunte em português mesmo: "como faço para...?"
  4. No terminal, /exit sai. Nada se perde: claude -c volta.
