Como o if / else decide?

Uma condição permite ao programa escolher o que fazer. Por exemplo: se a nota for pelo menos 7, aprova; se não, verifica se chegou a 5; caso contrário, reprova.

Decisão com if / else if / else

if (nota >= 7) {
  resultado = "Aprovado";
} else if (nota >= 5) {
  resultado = "Recuperação";
} else {
  resultado = "Reprovado";
}

O JavaScript testa as condições de cima para baixo e executa o primeiro bloco verdadeiro. Se nenhuma condição anterior for verdadeira, executa o else.

Outro jeito: if dentro de if (aninhado)

Dá para chegar ao mesmo resultado colocando um if dentro do else de outro. Repare que o teste é media < 5 para reprovar, e "Recuperação" vira o último else. 

if (media >= 7) {
  console.log("Aprovado!");
} else {
  if (media < 5) {
    console.log("Reprovado :(");
  } else {
    console.log("Recuperação. Estude mais para passar.");
  }
}

O resultado é o mesmo do else if, mas o else if costuma ser mais fácil de ler, porque evita blocos dentro de blocos.

if / else x ternário

Quando só existem duas respostas, o ternário faz o mesmo que o if / else, em uma linha. 

// com if / else
let mensagem = "";
if (media >= 7) {
  mensagem = "Aprovado";
} else {
  mensagem = "Reprovado";
}

// com ternário
let mensagem = media >= 7 ? "Aprovado" : "Reprovado";

Leia assim: condição ? se verdadeira : se falsa. Com três respostas (aprovado, recuperação, reprovado), prefira o if / else if / else, que é mais fácil de ler.
