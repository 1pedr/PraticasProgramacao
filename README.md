# Práticas de Programação

Anotações e exercícios do curso de Práticas de Programação (HTML, CSS e JavaScript).

## Páginas

| Arquivo              | Conteúdo                                                         |
| -------------------- | ---------------------------------------------------------------- |
| `aulas/introducao.html`    | Página inicial do curso                                          |
| `aulas/basico.html`        | HTML básico: textos, listas, links, imagens, tabela e formulário |
| `aulas/javascript.html`    | Introdução ao JavaScript                                         |
| `aulas/variaveis.html`     | Variáveis                                                        |
| `aulas/entrada-saida.html` | Entrada e saída de dados                                         |
| `aulas/operadores.html`    | Operadores                                                       |
| `aulas/condicionais.html`  | Decisões com if/else e operador ternário                         |
| `aulas/verificador.html`   | Verificador interativo de notas                                  |
| `aulas/switch.html`        | Switch case: cases, break, default e cases empilhados           |
| `aulas/repeticao.html`     | Repetição com while e do...while, contadora, acumuladora e teste de mesa |
| `aulas/for.html`           | Laço for (contar, tabuada, regressiva), for...in (objetos) e for...of (arrays e textos) |
| `aulas/arrays.html`        | Arrays: criar, acessar, push, unshift, pop, shift, splice e sort (laboratório) |
| `aulas/matrizes.html`      | Arrays multidimensionais: [linha][coluna], console.table e for aninhado |
| `aulas/funcoes.html`       | Funções: declaração, expressão, arrow, construtora (new) e geradora (yield) |
| `aulas/recursividade.html` | Recursividade: caso base, fatorial, for x recursão e onde se usa |
| `aulas/pratica.html`       | Prática: jogo da velha com matriz e funções, Fibonacci recursivo x for |
| `aulas/bootstrap.html`     | Bootstrap: o que é, como ligar por CDN, o que tem no link, grade, espaçamento e classes do carrinho |
| `aulas/desafio.html`       | Desafio com prompt e calculadora de operações aritméticas        |
| `aulas/glossario.html`     | Glossário de tags HTML e comandos JS do caderno, com busca       |
| `aulas/claude-code.html`   | Guia básico do Claude Code: pedidos prontos, comandos e atalhos  |

## Estrutura

```
aulas/    caderno de aulas, tudo junto: páginas .html, js/ e css/
carrinho/ projeto do carrinho de compras (Bootstrap)
.github/  agente "professor" usado no editor
```

Para ver, abra `aulas/introducao.html` no navegador.
