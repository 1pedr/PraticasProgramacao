Introdução ao JavaScript

O que é JavaScript?

O HTML cria a estrutura da página e o CSS cuida da aparência. O JavaScript dá comportamento: reage a cliques, faz contas, valida formulários, muda a página sem recarregar.

Como o JavaScript entra na página

Nestas páginas, cada assunto tem o seu arquivo na pasta js/, ligado ao HTML com esta tag, no final do <body>:

<script src="js/variaveis.js"></script>

Dica: abra o console do navegador com F12 para ver mensagens e erros do seu código.

Conteúdo

  1. Variáveis: guardar valores com nome (let, const, tipos).
  2. Entrada e Saída: mostrar informações e receber dados do usuário.
  3. Operadores: contas, comparações e condições lógicas.
  4. Condicionais: decisões com if, else if, else e ternário.
  5. Switch: escolha entre vários valores possíveis usando case, break e default.
  6. Repetição: repetir código com while e do...while.
  7. For: repetir um número conhecido de vezes, e percorrer objetos (for...in) e listas (for...of).
  8. Verificador: pratique a classificação de notas com condicionais.
  9. Desafios: some, subtraia, multiplique, divida, calcule o resto e a potência.
